# Tandem's compatibility policy for the Admin API contract, as oasdiff severity levels (LLD-api-stability §6.2).
#
# One line per rule whose level Tandem sets apart from upstream, `<rule-id> <level>`, grouped under the contract
# rule each group implements; the level is err, warn or info. Every other rule keeps the level the pinned image
# gives it. A finding at err or warn fails checkOpenApi unless gradle/accepted-breaks.txt declares its
# fingerprint; a finding at info passes. Left at their upstream info, so not listed: an element added, a request
# constraint relaxed, documentation, annotations and lifecycle, and the judgement calls below that list no rule.
#
# oasdiff rejects a comment or a blank line in this file, so checkOpenApi strips both into
# build/openapi/severity-levels.txt and hands oasdiff that copy; oasdiff rejects a rule id it does not know.
#
# The file is reviewed against the image named by the reviewed-with line: checkOpenApi fails while the version
# catalog pins another one. After an image upgrade, list the info rules the new image adds, classify each here,
# and move the line:
#   comm -13 <(docker run --rm tufin/oasdiff:<old> checks changelog --severity info --format text \
#       | awk 'NR > 1 { print $1 }' | sort) \
#     <(docker run --rm tufin/oasdiff:<new> checks changelog --severity info --format text \
#       | awk 'NR > 1 { print $1 }' | sort)
reviewed-with tufin/oasdiff:v1.33.0
