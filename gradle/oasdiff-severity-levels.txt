# Tandem's compatibility policy for the Admin API contract, as oasdiff severity levels (LLD-api-stability §6.2).
#
# One line per rule, `<rule-id> <level>`, grouped under the contract rule each group implements; the level is
# err, warn or info. A finding at err or warn fails checkOpenApi unless gradle/accepted-breaks.txt declares
# its fingerprint; a finding at info passes. Every rule the pinned oasdiff image classes as info is listed,
# raised to err or kept at info as a statement that the change is compatible for Tandem: checkOpenApi fails
# while one is missing, or while a line names a rule the image does not have. A rule upstream classes as
# warn or err keeps its level and is not listed, except the one the first group lowers.
#
# oasdiff rejects a comment or a blank line in this file, so checkOpenApi strips both into
# build/openapi/severity-levels.txt and hands oasdiff that copy. After an image upgrade, the failure of
# checkOpenApi names each new info rule to classify here.
#
# The file was written once from the catalog of the pinned image, every info rule at info, then classified by
# editing it:
#   docker run --rm tufin/oasdiff:v1.33.0 checks changelog --severity info --format text \
#     | awk 'NR > 1 { print $1, "info" }'
