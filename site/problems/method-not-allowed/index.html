405

Method not allowed

https://tandem.codingful.com/problems/method-not-allowed

What it means

The path exists, but not for this HTTP method: a GET on an action that only accepts POST, for instance. The response carries an Allow header listing the methods the path does accept.

What to do

Send the request with one of the methods in Allow. The operations and their methods are listed in the OpenAPI contract; every action that changes state is a POST, every read a GET.

Example

{
  "type": "https://tandem.codingful.com/problems/method-not-allowed",
  "title": "Method not allowed",
  "status": 405,
  "detail": "This path does not accept the request method; the Allow header lists the ones it does"
}
