406

No acceptable representation

https://tandem.codingful.com/problems/not-acceptable

What it means

The request's Accept header admits nothing the operation can return. Every operation answers application/json, and every error application/problem+json; this problem itself is sent as application/problem+json whatever the header says, since nothing else could carry it.

What to do

Accept application/json (and application/problem+json for errors), or send no Accept header at all. A client that only asks for another format, such as CSV, cannot be served by this API.

Example

{
  "type": "https://tandem.codingful.com/problems/not-acceptable",
  "title": "No acceptable representation",
  "status": 406,
  "detail": "The Accept header admits no representation this operation returns"
}
